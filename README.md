# Python-клиент системы бронирования номеров в гостинице

## 1. Назначение проекта

Python-клиент является пользовательской частью системы бронирования номеров в гостинице. Он предназначен для взаимодействия с серверным COM-компонентом, реализованным на языке C++.

Клиент предоставляет программный интерфейс для выполнения операций с номерами, бронированиями и статистикой гостиницы. Взаимодействие с сервером осуществляется через технологию COM (Component Object Model).

В проекте используется библиотека `pywin32`, позволяющая обращаться к COM-объектам из Python.

## 2. Архитектура клиента

Клиентская часть разделена на несколько модулей:

```text
HotelClient/
├── hotel_client/
│   ├── __init__.py
│   ├── connection.py
│   ├── rooms.py
│   ├── bookings.py
│   └── reports.py
├── tests/
│   ├── test_connection.py
│   ├── test_rooms.py
│   ├── test_bookings.py
│   ├── test_reports.py
│   ├── test_errors.py
│   └── test_mvp_methods.py
├── demo.py
├── requirements.txt
└── README.md
```

### Описание модулей

**`connection.py` — подключение к серверу**

Модуль отвечает за создание и освобождение COM-соединения. Он инициализирует COM для текущего потока, создаёт экземпляр серверного объекта по его CLSID и предоставляет доступ к методам гостиничной системы.

Для корректного управления ресурсами используется контекстный менеджер `with`. После завершения работы соединение освобождается.

**`rooms.py` — работа с номерами**

Модуль содержит функции для взаимодействия с номерами гостиницы:

- проверка доступности номера;
- получение информации о номере;
- поиск номеров по типу;
- поиск свободных номеров на заданный период;
- изменение статуса номера;
- добавление, обновление и удаление номеров.

**`bookings.py` — работа с бронированиями**

Модуль предоставляет функции для управления бронированиями:

- создание бронирования;
- получение информации о бронировании;
- изменение дат проживания;
- расчёт стоимости;
- применение скидки;
- заселение и выселение гостя;
- бронирование и отмена бронирования с помощью базовых методов `BookRoom` и `CancelBooking`.

**`reports.py` — отчётность**

Модуль получает от сервера статистику гостиницы и преобразует JSON-ответ в структуру Python для дальнейшего использования.

**`demo.py` — демонстрационная программа**

Демонстрационный сценарий предоставляет консольное меню для проверки возможностей системы. Пользователь выбирает операцию, вводит необходимые данные, после чего клиент вызывает соответствующий метод COM-сервера и выводит результат.

**`tests/` — автоматические тесты**

Каталог содержит тесты для проверки подключения, работы с номерами, бронированиями, отчётностью, обработки ошибок и базовых методов MVP.

## 3. Взаимодействие с сервером

Клиент не реализует основную бизнес-логику гостиницы самостоятельно. Он вызывает методы COM-сервера, который выполняет операции и возвращает результаты.

Общая последовательность взаимодействия:

1. Python инициализирует COM.
2. Клиент создаёт экземпляр серверного COM-объекта по CLSID.
3. Python вызывает методы объекта через интерфейс `IDispatch`.
4. C++-сервер выполняет запрошенную операцию.
5. Результат возвращается клиенту.
6. Клиент преобразует результат в удобный для Python формат.
7. После завершения работы COM-соединение освобождается.

Для передачи структурированных данных сервер использует JSON-строки. Клиент преобразует их в словари или списки Python с помощью модуля `json`.

## 4. Используемые технологии

- **Python** — реализация клиентской части.
- **pywin32** — взаимодействие с COM-объектами Windows.
- **COM / IDispatch** — механизм вызова методов серверного компонента.
- **JSON** — передача структурированных данных между клиентом и сервером.
- **pytest** — автоматизированное тестирование.

## 5. Установка зависимостей

Необходимо установить Python для Windows и подготовить окружение проекта.

В терминале перейдите в каталог `HotelClient` и выполните:

```bash
python -m pip install -r requirements.txt
```

Файл `requirements.txt` содержит:

```text
pywin32
pytest
```

## 6. Запуск клиента

Перед запуском необходимо собрать C++ COM-сервер и зарегистрировать его в Windows. Подробная инструкция приведена в README серверной части.

Для запуска демонстрационной программы выполните из каталога `HotelClient`:

```bash
python demo.py
```

После запуска откроется консольное меню с доступными операциями.

## 7. Запуск тестов


Для запуска автоматических тестов выполните:

```bash
python -m pytest -v
```

Если требуется увидеть вывод `print()` из тестов:

```bash
python -m pytest -v -s
```

Тесты проверяют корректность вызова методов сервера, обработки возвращаемых значений и поведения клиента при различных сценариях.

## 8. Результат

Python-клиент обеспечивает взаимодействие пользователя с серверной частью гостиничной системы. Благодаря разделению на модули код организован по назначению: подключение к COM-серверу, работа с номерами, бронированиями и статистикой.

Такое разделение упрощает сопровождение программы, повторное использование функций и тестирование взаимодействия между компонентами.
